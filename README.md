# LINE 對話復刻器

適用於給那些不小心將line重裝又沒有備份的人且剛好在電腦版的line中還有對話還沒同步
使用前請先在電腦的line下載對話的.txt檔，你會發現那個txt檔很不易讀，故可以使用本工具

可以將 LINE 匯出的 `.txt` 對話紀錄載入網頁，在瀏覽器中重新呈現成聊天介面，並提供**關鍵字搜尋、搜尋結果跳轉與圖片匯出**功能。

> 🔒 **隱私說明**
>
> 對話檔案由瀏覽器端 JavaScript 直接讀取與解析，程式沒有將聊天內容上傳至後端伺服器的功能。

---

## ✨ 功能

- 📄 讀取 LINE `.txt` 對話紀錄
- 💬 將文字紀錄重新呈現成聊天泡泡
- 👤 自訂自己的顯示名稱
- 🔍 關鍵字搜尋
- 📌 搜尋結果快速跳轉
- ✨ 搜尋結果高亮顯示
- 📸 將目前對話匯出成 PNG 圖片
- 🔒 對聊天內容進行 HTML Escape，降低 XSS 風險

## 📱 使用流程

### Step 1：輸入自己的顯示名稱

在：

> `1. 輸入你在對話中的顯示名稱`

輸入你在 LINE 對話紀錄中使用的名稱。

例如：

```text
小明
```

程式會利用這個名稱判斷哪些訊息是「我」。

---

### Step 2：選擇 LINE `.txt` 備份檔

點擊：

> `2. 選擇 LINE 的 .txt 備份檔`

選擇 LINE 匯出的 `.txt` 對話紀錄。

目前網頁只接受 `.txt` 檔案作為輸入。

選擇檔案後，程式會在瀏覽器中讀取內容並解析對話。

---

### Step 3：查看對話

載入成功後，對話會重新呈現成類似聊天軟體的介面。

程式會根據你輸入的名稱判斷訊息：

```text
自己的訊息 → 右側
其他人的訊息 → 左側
```

---

### Step 4：搜尋聊天紀錄

在：

> `3. 關鍵字搜尋`

輸入想搜尋的內容。

例如：

```text
生日
```

然後按下：

```text
Enter
```

程式會列出符合的訊息，並將搜尋結果標記出來。

如果有多筆結果，可以從下拉選單選擇指定訊息，直接跳轉到該位置。

---

### Step 5：匯出對話圖片

點擊：

```text
📸 將當前對話匯出成圖片
```

程式會使用 `html2canvas` 將目前的聊天內容轉換成 PNG。

輸出的檔名預設為：

```text
LINE對話紀錄_匯出.png
```

## 🔐 隱私與安全性

這個工具主要在**使用者自己的瀏覽器中處理聊天紀錄**。

TXT 檔案透過：

```javascript
FileReader
```

讀取後，在瀏覽器內進行解析。

目前提供的程式碼中沒有看到將聊天內容透過：

```text
fetch()
XMLHttpRequest
WebSocket
```

傳送到後端的程式。

另外，聊天訊息在插入 HTML 前會經過：

```javascript
escapeHtml()
```

處理，以降低惡意 HTML / JavaScript 被執行的風險。

---

## ⚠️ 注意事項

### 1. 大型聊天紀錄

如果 TXT 檔案非常大，瀏覽器需要一次解析並建立大量 DOM 元素。

因此可能出現：

- 網頁卡頓
- 記憶體使用量增加
- PNG 匯出失敗

程式目前也會提示：

> 若對話太長，可能無法完整匯出



---

### 2. 圖片匯出使用 html2canvas

圖片匯出功能使用：

```text
html2canvas
```

目前透過 CDN 載入：

```html
https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js
```

- 圖片匯出受到瀏覽器 Canvas 大小限制
